    Kamaitachi

    Authorizing gives Mikata a token that can only submit scores. The token stays on this device, and you can remove or revoke it at any time.

    Mikata can only submit scores. Removing the authorization deletes the token here; to revoke it completely, delete the matching API key under Integrations on your Kamaitachi profile.

    This build of Mikata has no Kamaitachi OAuth2 client configured, so authorizing is not available yet.

    For developers: create an OAuth client under Integrations on your Kamaitachi profile, set its Redirect URI to the address below, and request only the submit_score permission. Then put the client ID and client secret in .env.local and rebuild.

    Everything after the domain is ignored.

    Most servers give play times in UTC. If this one gives them in its own time zone, choose that zone, and Mikata corrects the times before uploading.
